Instructions on Vim

Opening and closing vim

To open vim and close vim, you will need to type in your terminal the following.
            Opening: vim filename.txt | example: vim index.html
            Closing: ESC + : + wq, this'll close vim | example: :wq / to close without saving: ESC then type ( :q! )
            Entering the commands + keys
vim filename.txt

Entering it wrong will result in opening a new vim file.

ESC + :wq

Entering a command wrong will display this error message.

Not an editor command: (Typed Command)

To exit editor mode, you use ESC, this'll allow you to use commmands in Vim as well.

Moving in Vim command mode

These are instructions on how to move and edit in vim.

  • H Key - Goes Left.
  • J Key - Goes Down.
  • K Key - Goes Up.
  • L Key - Goes Right.
    i — Insert before the current cursor position.
    I — Move to the beginning of the current line (first non-blank character) and enter insert mode
    a — Append after the current cursor position.
    A — Move to the end of the current line and append text.
    o — Open a new line below the current line and enter insert mode.
    O — Open a new line above the current line and enter insert mode.

Commands in Command-Mode

These are commands that can be used in command mode

  • Hightlighting code
    1. syntax on
    2. Enable syntax highlighting for code
    • Code Lines
    1. set number
    2. Show line numbers on the left
